# श्री हनुमान मंदिर, देहरिया (Maharajganj, Bhadohi) - Devotional Website

एक अत्यंत सुंदर, तीव्रगामी, मोबाइल-अनुकूल (mobile-first) एवं शांतिदायक आध्यात्मिक वेबसाइट जो ग्राम देहरिया, महाराजगंज, भदोही (उत्तर प्रदेश – 221314) स्थित श्री हनुमान मंदिर एवं सभी सनातन श्रद्धालुओं के लिए समर्पित है।

---

## 🚩 प्रमुख विशेषताएँ (Key Features)

1. **संपूर्ण श्री हनुमान चालीसा**:
   - पारंपरिक दोहे (आरंभिक व समापन) एवं सभी ४० चौपाइयाँ शुद्ध देवनागरी में।
   - अक्षर आकार नियंत्रण (`A+` / `A-` / सामान्य रीसेट) वरिष्ठ श्रद्धालुओं हेतु।
   - संपूर्ण पाठ एक क्लिक में कॉपी करने की सुविधा।
   - शांत पठन मोड (Distraction-Free Reading Mode) एवं प्रिंट सुविधा।
   - वेब शेयर (Web Share API) व क्लिपबोर्ड शेयर।

2. **श्री हनुमान जी की पावन आरती**:
   - पारंपरिक आरती: *"आरती कीजै हनुमान लला की"*, शुद्ध छंद व पद।
   - अनुकूलित अक्षर आकार, कॉपी, शेयर एवं प्रिंट विकल्प।

3. **हनुमान जी की ८ पावन कथाएँ**:
   - १. हनुमान जी का जन्म
   - २. बाल हनुमान और सूर्य देव
   - ३. श्री राम और हनुमान जी की पहली भेंट
   - ४. समुद्र लांघकर लंका पहुँचना
   - ५. अशोक वाटिका में माता सीता से भेंट
   - ६. लंका दहन
   - ७. संजीवनी बूटी लाना
   - ८. श्री राम के प्रति हनुमान जी की अनन्य भक्ति
   - प्रत्येक कथा में भावपूर्ण आख्यान, शिक्षा (Moral) और अगली/पिछली कथा नेविगेशन।

4. **भक्ति छवि दीर्घा (Devotional Gallery)**:
   - प्रभु हनुमान जी, आरती दीप, मंदिर शिखर एवं पवित्र प्रतीकों का उच्च गुणवत्ता युक्त स्थानीय संग्रह।
   - श्रेणी अनुसार फिल्टर (श्री हनुमान जी, आरती एवं दीप, मंदिर एवं भक्ति)।
   - पूर्ण आकार लाइटबॉक्स (Lightbox) - Next, Previous, Close, Escape कुंजी समर्थन सहित।

5. **मंदिर जानकारी एवं सत्यापित स्थिति (Verified Transparency)**:
   - ग्राम: देहरिया, डाकघर: महाराजगंज, जनपद: भदोही, उत्तर प्रदेश – 221314।
   - गूगल मैप्स नेविगेशन लिंक।
   - पारदर्शी सूचना नीति (आरती समय एवं व्यवस्थापक विवरण आधिकारिक पुष्टि उपरांत)।
   - एकल विन्यास फ़ाइल (`src/data/temple.js`) जिससे भविष्य में विवरण बदलना अत्यंत सरल है।

6. **भक्ति, दोहे एवं विचार (Bhakti & Quotes)**:
   - श्री रामचरितमानस, सुंदरकांड, विनय पत्रिका एवं चालीसा के प्रामाणिक दोहे।
   - प्रत्येक दोहे का सरल हिंदी भावार्थ व प्रसंग।

7. **मोबाइल-प्रथम एवं सुगमता (Mobile-First & Accessibility)**:
   - 320px से लेकर 1920px तक सभी स्क्रीन्स पर बिना किसी क्षैतिज स्क्रॉल (No Horizontal Scroll) के उत्कृष्ट प्रदर्शन।
   - ४४x४४px न्यूनतम टच-टार्गेट।
   - ४-टैब त्वरित मोबाइल बॉटम नेविगेशन (होम, चालीसा, आरती, कथाएँ)।
   - उच्च कन्ट्रास्ट, स्वच्छ देवनागरी टाइपोग्राफी (Noto Sans Devanagari)।
   - WCAG 2.2 AA सिद्धांतों का पालन।

## 🛠️ प्रयुक्त तकनीकें (Technology Stack)

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS (कस्टम सात्विक रंग: भगवा `#F28C28`, गहरा भगवा `#C65316`, मंदिर लाल `#8B1E1E`, क्रीमी बैकग्राउंड `#FFF8E8`, स्वर्ण `#D4A64A`)
- **Routing**: React Router DOM v6
- **Icons**: Lucide React
- **Static & Clean**: शून्य बाहरी डेटाबेस, शून्य विज्ञापन, शून्य जटिल बैकएंड।

## 🌐 Vercel पर निःशुल्क परिनियोजन (Vercel Deployment)

प्रोजेक्ट पहले से ही `vercel.json` SPA रीराइट नियमों के साथ सुसज्जित है।

### चरण-दर-चरण निर्देश:
1. अपने कोड को GitHub रिपॉजिटरी में पुश करें।
2. [Vercel](https://vercel.com) में लॉगिन करें।
3. **"Add New Project"** पर क्लिक करें और अपनी GitHub रिपॉजिटरी को इम्पोर्ट करें।
4. **Framework Preset** में `Vite` स्वतः चुना जाएगा।
5. **Build Command**: `npm run build`
6. **Output Directory**: `dist`
7. **Deploy** बटन पर क्लिक करें।
8. परिनियोजन पूर्ण होते ही सभी यूआरएल (सीधे लिंक, रिफ्रेश करने पर भी) सुचारू रूप से कार्य करेंगे।
